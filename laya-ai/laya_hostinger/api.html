📬 Query Payload Specification

                        
Send JSON body to POST /query with the following schema:

                        
{
  "text": "Context paragraph or document to evaluate (string, required)",
  "question": "Question or condition to test (string, required)",
  "type": "noul | choice (string, default: 'noul')",
  "options": "Comma-separated options if type is choice (string, optional)"
}

                                Traditional LLMs (GPT-4, Claude) process decision making via autoregressive generation: they must generate tokens one by one, introducing latency (2-5 seconds), high token costs, and risk of hallucination.
                            

                            

                                Laya AI implements a non-autoregressive System 1 classifier. By evaluating the input context and question in a single forward pass, it yields deterministic decisions, probability scores, and typed classifications in sub-second (~500ms on this 2 vCPU server, and <150ms on GPU hardware).
